# 全球地址数据源清单 v1

> 调查日期：2026-10-09
> 调查方式：全量 HTTP 实测（未下载数据，仅验证源是否存在 / 是否有 API / 返回什么）
> 采集铁律：**只收真实门牌点数据；区间数据只取每侧两端；中间号一律丢弃；绝不编造。**

---

## 0. 优先级总览

| 优先级 | 层 | 为什么 |
|---|---|---|
| **P0** | 聚合层 + 目录检索层 | 一次拿到"最大公约数"，并能定位所有县市级源 |
| **P1** | 联邦级（TIGER） | 覆盖 100%，公有领域零限制 |
| **P2** | 州级（全州统一地址库） | 一次拿一个州，性价比极高 |
| **P3** | 县市级（最真最细） | 数量最大，用于补缺口 |
| **P4** | 校验 / 商业 API | 不产数据，只做校验与补字段 |
| **P5** | 其他国家官方全量源 | 多国扩展阶段启用 |

## A. 聚合层与检索层（P0 · 先吃这一层）

### A1. OpenAddresses ★核心
| 项 | 内容 |
|---|---|
| 状态 | ✅ 存在（`openaddresses.io` 200 / `results.openaddresses.io` 200） |
| 源清单 | https://results.openaddresses.io/ （页面 3.4MB，含全部源） |
| **美国源数量** | **1,877 个独立数据源**（实测统计，德州 305、北卡 111、加州 107、佐治亚 100、俄亥俄 92…） |
| 批量下载 | `https://data.openaddresses.io/openaddr-collected-us_west.zip`（1.10GB）、`us_northeast`（611MB）、`us_midwest`（927MB）、`us_south`（2.51GB）；全球 `openaddr-collected-global.zip`（13.4GB） |
| 逐源下载 | 结果站每个源有 `<source>.zip`，落在 **Requester-Pays（请求方付费）的 S3 桶**上，匿名直连 403，需 AWS 账号 + `--request-payer requester` 并自付流量费（≈$0.09/GB）⚠️ **——但路线三可完全绕开，见下** |
| **源定义库（GitHub，免费）** ★推荐 | `https://github.com/openaddresses/openaddresses/tree/master/sources/us` —— 53 个州目录，每个源一个 JSON，内含**原始数据 URL、attribution、license URL、protocol（ESRI/HTTP/SHP）、字段映射（number/street/city/region/postcode）**。实测 Anchorage 样例：`data=https://services2.arcgis.com/.../FeatureServer/0`、`protocol=ESRI`、`number←HOUSE_NUMBER+HALF_ADDRESS`。**等于别人已经替我们整理好了全美 1,877 个源的入口+授权+字段对应** |
| 数据格式 | **OA 标准 CSV：`LON,LAT,NUMBER,STREET,UNIT,CITY,DISTRICT,REGION,POSTCODE,ID,HASH`** —— 天然就是**点级**，完全符合我们的铁律 |
| 采集方式 | 脚本 HTTP 下载 zip → 解压 CSV → 直读（无需解析 shapefile，最省事） |
| 授权 | 逐源不同，多数要求署名（CC-BY / 公有领域） |
| 坑 | 逐源下载要 AWS 账号（**可以不用**）。推荐取数路线：**读 GitHub 源定义 → 按 protocol 分派适配器 → 直连原点拉**（免费 + 保留来源 + 保留授权） |

### A2. OpenStreetMap / OSM ★全球唯一通用源
| 项 | 内容 |
|---|---|
| 状态 | ✅ 全部实测可用 |
| 按州下载 | https://download.geofabrik.de/north-america/us.html ；加州 pbf **1.33GB**（实测 200） |
| Overpass API | https://overpass-api.de/api/interpreter （状态接口 200）→ 可用 QL 按县/市拉 `addr:housenumber` |
| Nominatim | https://nominatim.openstreetmap.org/search （200，限 1 req/s） |
| 采集方式 | ① pbf 路线：`osmium tags-filter --expressions='n/addr:housenumber'` 或 pyosmium，过滤后导出 CSV（推荐，可控）② Overpass 路线：按区域拉，适合小范围补缺 |
| 授权 | **ODbL：署名 + 衍生数据同许可（有传染性）** ⚠️ 商用需法务确认 |
| 价值 | 全球唯一能覆盖"美国以外"的通用源 |

### A3. ArcGIS Online / Hub ★县市级金矿的集中入口
| 项 | 内容 |
|---|---|
| 状态 | ✅ 实测可用 |
| 全站搜索 API | `https://www.arcgis.com/sharing/rest/search?q=<关键词> type:"Feature Service"&f=json` → 搜 "address points" 实测 **8,528 个要素服务** |
| Hub 数据集 API | `https://hub.arcgis.com/api/v3/datasets?q=<关键词>&page[size]=N` |
| 数据拉取 API | `https://<FeatureServer>/query?where=1%3D1&outFields=*&f=geojson&resultOffset=N&resultRecordCount=2000`（**单次上限 2000 条，必须分页**）；先用 `returnCountOnly=true` 估总量 |
| 采集方式 | 搜索 → 拿 FeatureServer URL → 分页 query → GeoJSON/JSON → 清洗 |
| 授权 | 多数 CC-BY / 公有领域，逐条看 |
| 价值 | **缺口补采的主力工具**（一个 API 打通全国几千个县市门户） |

### A4. Socrata 目录 ★城市开放数据主力
| 项 | 内容 |
|---|---|
| 状态 | ✅ 实测可用 |
| 目录 API | `https://api.us.socrata.com/api/catalog/v1?q="address points"&limit=N` → 实测 **2,488 个数据集** |
| 数据 API | `https://<domain>/resource/<id>.json?$limit=50000&$offset=N`（支持 `$where` / `$select`） |
| 实测样例 | Cook County IL `https://datacatalog.cookcountyil.gov/resource/78yw-iddh.json` ✅ 真实门牌点，字段：`add_number, st_predir, st_name, st_type, placename, state, post_code, lat, long, pin, geocode_muni` |
| 其它实测样例 | Pierce County WA `internal.open.piercecountywa.gov/resource/ewun-9uc6.json`；New Orleans `data.nola.gov/resource/hfvu-md72.json`；Bloomington IN `data.bloomington.in.gov/resource/b8yb-iwu6.json`；Cambridge MA `data.cambridgema.gov/resource/4ftb-8ne5.json` |
| 采集方式 | 目录搜索 → 拿 domain+id → 分页拉 JSON → 清洗 |
| 授权 | 多数公开开放，逐条看 |

## F. 采集方式速查（按源类型）

| 源类型 | 采集方式 | 单次上限 | 是否需要 Key |
|---|---|---|---|
| OpenAddresses 批量包 | HTTP 下载 zip → 解压 CSV | 无 | 否 |
| OpenAddresses 逐源 | S3 下载（**Requester-Pays，需 AWS 账号**） | 无 | AWS 账号 |
| OSM / Geofabrik | 下载 pbf → osmium/pyosmium 过滤 | 无 | 否 |
| OSM / Overpass | POST QL 查询 | 按区域 | 否（限速） |
| ArcGIS FeatureServer | `query` 分页（`resultOffset`） | **2000 条/次** | 否（多数） |
| Socrata | `/resource/<id>.json?$limit&$offset` | 50000 条/次 | 否（多数） |
| TIGER/Line | 按县下载 zip → shapefile → CSV | 无 | 否 |
| 州/县门户 | 多数是 ArcGIS/Socrata → 同上；少数直接发 zip | 视门户 | 少数需注册 |

## G. 关键结论与风险

1. **先吃 P0（OpenAddresses + OSM + ArcGIS/Socrata 检索），再补缺口** —— 能省掉 ~70% 的县市级手工活。
2. **OpenAddresses 的逐源下载卡在 Requester-Pays S3** —— 优先用 4 个美国批量包（合计 5.15GB）。
3. **census.gov 从本机 403，但 Actions 在美国 IP 上大概率正常** —— 一期必须先验证这一条，它决定 TIGER 能不能用。
4. **Census Geocoder 不能验证门牌是否存在**（区间插值）—— 不要拿它当"真实性校验器"。
5. **授权风险**：TIGER = 公有领域（最安全）；OSM = ODbL（传染性）；OpenAddresses = 逐源不同（多数需署名）。**TIGER 优先，OSM 用于补缺。**
6. **ArcGIS/Socrata 是两条万能通道** —— 一个适配器打通全国几千个县市，这是采集工程的核心工作量所在。
