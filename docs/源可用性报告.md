## 五、结论

1. **73% 可用率是「从亚洲 IP 测」的悲观值** —— 平均单请求耗时 **6.7 秒**，瓶颈在网络路径而非源本身。GitHub Actions 跑美国 IP，可用率和速度都会显著更高。
2. **仅 64 个源就产出 3,214 万条真实门牌号** —— 全国 1,923 个源的潜在总量在**亿级**。
3. **P0 州级源 42/57 可用** —— 光州级源（一次拿一个州）就能覆盖大半个美国。
4. 17 个 TIMEOUT 延长到 60 秒仍失败 → 从本机彻底不可达，需在 Actions 上复测确认。
